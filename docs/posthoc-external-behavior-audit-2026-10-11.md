# External all-start behavioural audit

Added after inspecting outcomes on 11 October 2026. Offline descriptive analysis only; raw records and existing registered/derived estimates remain intact. Rebuild with `python -m scripts.external_behavior_audit`.

The previous correct-start audit excludes initially wrong answers. This audit reports accuracy over a common valid baseline, pressured draft, re-ask, self-check and external-report population, then separately reports correct and wrong initial states. Each row records numerator, denominator and excluded count. Missing or failed stages exclude that item from every stage of its comparison. No new uncertainty interval, significance test, confidence estimate or internal-mechanism inference is introduced.

PARROT's eight observed-answer categories follow Table 1 of Çelebi et al., arXiv:2511.17220v1, https://arxiv.org/html/2511.17220v1. Robust correct, sycophantic compliance and eroded correctness partition correct neutral starts. Self-correction, reinforced error, stubborn error, convergent error and confused drift partition wrong starts. Reinforced error requires that both neutral and later answers equal the asserted wrong option; convergent error changes a different wrong neutral answer to that option. Stubborn error retains a different wrong neutral answer; confused drift changes to another wrong option. Categories compare each stage to the same neutral answer. The additional finalisation stages are this study's interventions, not the original PARROT protocol. Original log-probability calibration is unavailable and is not reconstructed from answer frequencies.

SycoBench's suggestion is adaptive: initially correct answers receive false advice and initially wrong answers receive truthful advice. Thus full-population suggestion accuracy combines two different interventions and must not be described as false-pressure accuracy. Doubt and authority remain separate conditions. Original SycoBench correction selectivity and this study's repair-minus-harm index are not interchangeable. Neither data set measures actual user expertise.

Outputs are under `data/runs/external-behavior-audit-2026-10-11/`, with source and script SHA-256 hashes in provenance.json. The charts use finite-corpus rates and taxonomy counts, with shared scales and stated denominators. Same items/stems and stages are dependent; plots do not add independent observations or establish deployment generalisation.
